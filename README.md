# ChaldLauncher

Minecraft-лаунчер от Chald Studio (Electron + React + TypeScript).

## Запуск и сборка

```
npm install
npm run dev        # разработка (Vite + Electron)
npm run build      # сборка
npm test           # тесты
npm run dist:dir    # лаунчер без установщика -> release/win-unpacked
npm run installer   # свой установщик -> installer/release/ChaldLauncher-Setup.exe
```

Установщик описан в `installer/README.md`.

## Загрузчики

Vanilla, Fabric, Quilt, Forge (Minecraft 1.13+) и NeoForge (1.20.2+, включая 26.x).
Forge/NeoForge устанавливаются самим лаунчером: он скачивает установщик, берёт библиотеки через свой список
разрешённых хостов и запускает обработчики установщика с помощью Java. Сами обработчики обращаются к серверам
Mojang напрямую, эти запросы не видны на вкладке «Сетевые запросы».

## Modrinth

Страница «Modrinth» в боковом меню: поиск и установка модов, сборок (`.mrpack`) и ресурспаков.

- **Мод / ресурспак** скачивается в выбранный инстанс. У модов автоматически ставятся обязательные зависимости; версия подбирается под Minecraft и загрузчик инстанса. Файл с тем же именем не перезаписывается.
- **Сборка** создаёт новый инстанс: лаунчер скачивает файлы по списку из сборки (проверка SHA-1), копирует `overrides/` и `client-overrides/`, затем ставит нужную версию Minecraft и загрузчик. При ошибке или отмене созданный инстанс удаляется.
- Запросы идут только на `api.modrinth.com` и `cdn.modrinth.com` (для сборок ещё GitHub/GitLab, как разрешает формат .mrpack) и видны на вкладке «Сетевые запросы».

## Шрифт

`src/renderer/fonts/ChaldPixel.woff` — Pixelify Sans с перерисованными «е/Е», «в», «О», «П» (в оригинале кириллический набор неполный, а «е» похожа на зеркальную «э»). Один файл покрывает латиницу и кириллицу.

## Вход через Microsoft

Лаунчеру нужен **свой** Azure Client ID. ID официального Minecraft Launcher использовать нельзя: он принадлежит
Mojang, не предназначен для чужих программ, и лаунчер выдавал бы себя за официальный.

1. portal.azure.com → Microsoft Entra ID → App registrations → New registration.
2. Supported account types: «Personal Microsoft accounts only» (или «Accounts in any ... and personal»).
3. Redirect URI: платформа «Mobile and desktop applications», значение `http://localhost`.
   Authentication → «Allow public client flows» = Yes (нужно для входа по коду).
4. Скопируй Application (client) ID.
5. Подай заявку на доступ к Minecraft API: https://aka.ms/AppRegInfo (без одобрения Mojang вход закончится ошибкой
   вида «Invalid app registration»).
6. Вставь ID в `src/main/config.ts` (`DEFAULT_MS_CLIENT_ID`), чтобы он работал у всех пользователей. Поля для ввода в интерфейсе нет: ID зашит в сборку.

Вход идёт через системный браузер (PKCE, временный локальный порт). Если он недоступен, есть вход по коду.
Токены хранятся только в зашифрованном виде (safeStorage).

## Обновления лаунчера

Лаунчер проверяет последний релиз на GitHub (репозиторий по умолчанию `ChaldS-mods/ChaldLauncher`, можно заменить в Настройки → Обновления). Если версия новее и в релизе есть установщик (файл `.exe` с «Setup» в названии, например `ChaldLauncher-Setup.exe`, который собирает `npm run installer`), он скачивается в фоне в `<папка данных>/updates/<версия>/`, проверяется по размеру и SHA-256 (GitHub отдаёт его в поле `digest` файла релиза). Скачанное обновление ставится нажатием на кнопку «Установить … и перезапустить» слева внизу: лаунчер запускает установщик с `--silent --launch` и закрывается. Пока идёт игра, установка не запускается.

- Автоскачивание выключается в Настройках; тогда на кнопке будет «Скачать vX».
- На Linux/macOS файла установки нет: кнопка только сообщает о новой версии.
- Чтобы автообновление нашло файл, на странице релиза должен лежать установщик `.exe`.

## Звуки

Короткие звуки при нажатии кнопок синтезируются прямо в окне (Web Audio), файлов нет. Включаются и настраиваются по громкости в Настройки → Звуки.

## Статус в Discord

Лаунчер показывает в Discord, что делает пользователь: «В главном меню · Chald Launcher», «В настройках», «Ищет моды на Modrinth», а во время игры «Играет в «Моя сборка»» с версией Minecraft, загрузчиком и временем с начала игры. Включается и выключается в Настройки → Discord; там же можно скрыть название инстанса. Статус идёт только в клиент Discord на этом же компьютере (локальный канал `discord-ipc`), без интернета, и работает при запущенном Discord для компьютера.

Чтобы статус заработал, нужно один раз создать приложение Discord:

1. https://discord.com/developers/applications → New Application. Название приложения Discord покажет как «Играет в …» (например, Chald Launcher).
2. Rich Presence → Art Assets → загрузи логотип лаунчера под именем `logo`.
3. Скопируй Application ID (General Information) и вставь в `src/main/config.ts` (`DEFAULT_DISCORD_CLIENT_ID`). Пока там пусто, статус выключен.

Тексты для страниц меняются в `src/main/presence.ts` (`PAGE_LABELS`).
