Установите

Скачайте файл для вашей системы. Права администратора не нужны: на Windows установщик ставит программу в профиль пользователя.

    Сборки

    Каждая сборка живёт в своём инстансе со своими модами, ресурспаками и настройками. Версию и загрузчик видно сразу.

    Modrinth внутри

    Поиск и установка модов, ресурспаков и целых сборок .mrpack. Обязательные зависимости ставятся сами, версия подбирается под инстанс.

    Все загрузчики

    Vanilla, Fabric, Quilt, Forge и NeoForge. Forge и NeoForge лаунчер устанавливает сам.

    Обновление модов

    Лаунчер сверяет установленные моды с Modrinth по хешу файла и предлагает обновить те, у которых вышла новая версия.

    Гардероб

    Библиотека скинов: импорт PNG 64×64 и 64×32, определение Steve и Alex, предпросмотр в 3D и смена скина.

    Память без возни

    Ползунки Xmx и Xms и автоподбор под число модов и ОЗУ компьютера. Системе всегда остаётся запас.

    Перенос сборок

    Экспорт и импорт одним файлом .chaldlauncher: моды с Modrinth скачиваются по списку с проверкой SHA-1, свои файлы едут внутри.

    Java сама

    Лаунчер ищет подходящую Java в системе, а если её нет, скачивает Temurin JRE в свою папку.

    Свой вид

    Четыре цвета интерфейса настраиваются, шрифт с исправленной кириллицей, звуки интерфейса можно отключить, статус в Discord по желанию.

      Вопросы и ответы

      Коротко о том, что спрашивают чаще всего.

      Нужен ли купленный Minecraft?

      Для входа на лицензионные серверы нужен аккаунт Microsoft с купленной игрой. Без него можно играть офлайн по нику (3–16 символов: латиница, цифры и «_»). Офлайн-режим честно офлайн и не притворяется аккаунтом Microsoft.

      Безопасно ли входить через Microsoft?

      Вход идёт через системный браузер, пароль лаунчер не видит. Если браузер недоступен, есть вход по коду. Токены хранятся только в зашифрованном виде и не попадают в интерфейс и журналы.

      Куда лаунчер ходит в интернет?

      Вкладка «Сетевые запросы» показывает все обращения: Mojang, Modrinth и список разрешённых адресов. Установщики Forge и NeoForge обращаются к серверам Mojang сами, эти запросы на вкладке не видны.

      Как обновляется лаунчер?

      Лаунчер проверяет последний релиз на GitHub, скачивает установщик и сверяет его SHA-256 перед запуском. Данные пользователя при обновлении не затрагиваются.

      Что происходит с моими данными при удалении?

      Данные лежат отдельно от программы. На Windows деинсталлятор отдельно спрашивает, удалять ли их, по умолчанию нет.

      Откуда берутся моды?

      Из каталога Modrinth. CurseForge пока не подключён. Свои моды можно положить в сборку вручную.

      Можно ли перенести сборку другу?

      Да: экспортируйте её в файл .chaldlauncher и отправьте. У друга лаунчер скачает моды с Modrinth по списку, проверит их хеши и распакует ваши конфиги и собственные файлы.

      Есть ли версия для macOS и Android?

      Пока нет. Сейчас лаунчер выходит для Windows и Linux на x64.

      Windows показывает предупреждение при запуске

      Нажмите «Подробнее» и проверьте издателя и имя файла. Скачивайте установщик только с этой страницы или со страницы релизов на GitHub.
