### Что нового

- **Автообновление.** Лаунчер сам находит новую версию на GitHub (при запуске и раз в 6 часов), скачивает её в фоне и ставит при закрытии. Работает в Windows и в Linux из AppImage. Выключается в Настройки → Обновления.
- **Смена версии и загрузчика.** В меню инстанса: «Сменить версию / загрузчик». Переход на другую версию Minecraft или на Fabric, Quilt, Forge, NeoForge без пересоздания инстанса. Перед переключением можно сохранить копию миров и отключить несовместимые моды; если установка не удалась, инстанс остаётся прежним.
- **Звуки кнопок.** Разные звуки для обычных кнопок, главной кнопки «Играть», опасных действий и переключателей. Включаются и настраиваются по громкости в Настройках → «Звуки».
- **Полная кастомизация лаунчера.** Можно менять цвета, темы и внешний вид интерфейса под себя.
- **Автоустановка сборок.** Лаунчер сам ставит сборки (модпаки) без лишних действий.
- **3D-гардероб.** Скин теперь можно рассматривать в 3D: вращение мышью, масштаб колесом, ходьба. Есть виды «3D», «Спереди», «Сзади». Если WebGL недоступен, показывается плоская кукла.
- **Лендинг.** Обновлённый сайт лаунчера.

### Файлы релиза

| Файл                      | Для чего                                       |
|---------------------------|------------------------------------------------|
| ChaldLauncher-Setup.exe   | Установщик для Windows (рекомендуется)         |
| ChaldLauncher-win-x64.zip | Windows без установки: распаковать и запустить |
| *.AppImage                | Linux, один файл                               |
| *.tar.gz                  | Linux, архив                                   |

### Известные ограничения

- Установщик не подписан, поэтому Windows SmartScreen может показать предупреждение.
- Автообновление работает в Windows и в Linux из AppImage. Для tar.gz и пакетов дистрибутивов лаунчер лишь сообщает о новой версии.
- 3D-гардероб: низ модели может быть повёрнут на 180°.
