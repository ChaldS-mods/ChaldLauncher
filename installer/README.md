# Установщик ChaldLauncher

Свой установщик с окном в стиле лаунчера (ChaldPixel, тёмная тема). Это отдельное маленькое Electron-приложение:
внутри лежит собранный лаунчер одним файлом `payload.chpk`, окно спрашивает папку и ярлыки, распаковывает файлы,
создаёт ярлыки и запись в «Приложения и возможности». Права администратора не нужны (установка на пользователя).

## Сборка

В корне проекта (Windows):

```
npm install
npm --prefix installer install
npm run installer
```

`npm run installer` делает по шагам: собирает лаунчер без установщика (`dist:dir` -> `release/win-unpacked`),
упаковывает его в `installer/payload/payload.chpk` и собирает `installer/release/ChaldLauncher-Setup.exe`.

Версия и название берутся из `package.json` лаунчера (`version`, `build.productName`, `build.appId`, `author`).

Отдельные шаги:

```
npm run dist:dir                    # лаунчер -> release/win-unpacked
cd installer
npm run payload                     # win-unpacked -> payload/payload.chpk (можно указать другую папку аргументом)
npm run dev                         # открыть окно установщика (нужен payload.chpk)
npm test                            # тесты ядра (формат архива, установка, обновление, защита от плохих архивов)
npm run dist                        # payload + electron-builder -> release/ChaldLauncher-Setup.exe
```

## Что делает установщик

- Папка по умолчанию: `%LOCALAPPDATA%\Programs\ChaldLauncher`. Кнопка «Обзор» добавляет к выбранной папке имя программы.
  Чужую непустую папку и корень диска установщик не трогает: ставит во вложенную папку `ChaldLauncher`.
- Копирует файлы во временную папку рядом (`…\ChaldLauncher.chald-new`), проверяет размер и SHA-256 каждого файла и только потом
  подменяет установленную копию. Если что-то пошло не так (диск заполнен, файл повреждён, отмена), старая версия остаётся как была.
- Обновление: если лаунчер уже установлен (запись в реестре + файл `.chald-install.json`), окно предлагает «Обновить» в ту же папку,
  запущенный лаунчер закрывается. Данные пользователя лежат отдельно (`%APPDATA%\ChaldLauncher`) и не затрагиваются.
- Ярлыки: рабочий стол и меню «Пуск» (по флажкам).
- «Приложения и возможности»: запись в `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\ChaldLauncher`.
- Удаление: `uninstall.ps1` в папке программы (запускается из «Приложения и возможности»). Спрашивает подтверждение и отдельно
  спрашивает, удалять ли данные пользователя (по умолчанию нет). Удаляет только папку, в которой есть маркер установщика.

## Тихая установка

```
ChaldLauncher-Setup.exe --silent [--dir "D:\Games\ChaldLauncher"] [--no-desktop] [--no-start-menu] [--launch]
```

Код выхода 0 при успехе, 1 при ошибке; журнал: `%TEMP%\ChaldLauncher-Setup.log`.

## Известные ограничения

- Установщик весит примерно как два лаунчера: внутри него свой Electron и сжатая копия лаунчера. Portable-exe при каждом запуске
  сначала распаковывает себя во временную папку, поэтому окно появляется через несколько секунд.
- Окно удаления стандартное (системное окно сообщений), а не в стиле лаунчера.
- Подпись кода не настроена: Windows SmartScreen покажет предупреждение для неподписанного exe.
