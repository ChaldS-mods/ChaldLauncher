## ChaldLauncher 0.3.0

### Что нового

- **Мультиязычность.** Четыре языка интерфейса: **русский**, **английский**, **қазақша (казахский)** и **беларуская (белорусский)**. Выбор в Настройки → Язык. Язык сохраняется в настройках лаунчера.
- Навигация, статус-бар, окна входа Microsoft, загрузка и блок настроек языка уже переведены. Остальные экраны постепенно переводятся на те же ключи i18n.
- **Шрифт ChaldPixel.** Добавлены казахские буквы (Ә Ғ Қ Ң Ө Ұ Ү Һ І) и белорусская І, переделана латинская Z — больше нет «чужих» букв из запасного шрифта.
- **Discord.** Зелёная кнопка «Наш Discord» в боковом меню и карточка сообщества на главной.
- **Настройки по вкладкам:** Основные, Аккаунт, Игра, Оформление, Discord.
- **Больше кастомизации** (Настройки → Оформление): масштаб интерфейса, стиль углов, пиксельный/обычный шрифт, сила свечения, анимации, компактное меню. Реклама Discord убрана с главной, карточка теперь во вкладке Discord в настройках.
- **DNS в настройках** (Настройки → Основные → Сеть): системный, свои DNS-серверы (по умолчанию `1.1.1.1`, `8.8.8.8`; есть пресеты Cloudflare, Google, Quad9) или **DoH** (DNS через HTTPS: Cloudflare, Google, Quad9 или свой адрес). Кнопка «Проверить DNS» пробует выбранный вариант до сохранения. Действует на запросы самого лаунчера; сама игра использует DNS системы.
- **Другие игры Mojang** (новая страница в меню, только Windows): **Minecraft Bedrock** запускается напрямую через протокол `minecraft:`, можно сразу добавить сервер в список игры. **Dungeons** и **Legends** открывают официальный Minecraft Launcher (игру выбираешь в нём). Если игры нет, кнопка «Получить» открывает страницу в Microsoft Store. Установку и лицензию ведёт Microsoft Store, лаунчер только находит и запускает.
- **Вкладка «Макет»:** отключение любых страниц меню, меню слева/справа, боковая панель справа/слева/снизу/скрыта и её ширина, строка состояния, свой CSS и свой HTML-блок на главной (HTML очищается от скриптов).

### Из 0.2.0-beta

- **Автообновление.** Лаунчер сам проверяет последний релиз на GitHub, в фоне скачивает установщик и проверяет его по размеру и SHA-256.
- **3D-гардероб.** Скин в 3D: вращение мышью, масштаб колесом, ходьба.
- **Звуки интерфейса.** Включаются и настраиваются по громкости в Настройках → «Звуки».
- **Свой установщик** `ChaldLauncher-Setup.exe` для Windows.

### Файлы релиза

| Файл | Для чего |
| --- | --- |
| `ChaldLauncher-Setup.exe` | Установщик для Windows (рекомендуется) |
| `ChaldLauncher-win-x64.zip` | Windows без установки: распаковать и запустить |
| `*.AppImage` | Linux, один файл |
| `*.tar.gz` | Linux, архив |

### Известные ограничения

- Установщик не подписан, поэтому Windows SmartScreen может показать предупреждение.
- Автообновление работает только в Windows. На Linux лаунчер лишь сообщает о новой версии.
- Часть строк на внутренних страницах (моды, детальные диалоги) пока на русском — полный перевод продолжится в следующих билдах.
