## ChaldLauncher 0.2.0-beta

Бета-версия: возможны ошибки, пожалуйста, пишите о них в Issues.

### Что нового

- **Автообновление.** Лаунчер сам проверяет последний релиз на GitHub, в фоне скачивает установщик и проверяет его по размеру и SHA-256. Установка запускается кнопкой «Установить … и перезапустить» слева внизу. Пока идёт игра, установка не стартует. Автоскачивание можно отключить в Настройках.
- **3D-гардероб.** Скин теперь можно рассматривать в 3D: вращение мышью, масштаб колесом, ходьба. Есть виды «3D», «Спереди», «Сзади». Если WebGL недоступен, показывается плоская кукла.
- **Звуки интерфейса.** Разные звуки для обычных кнопок, главной кнопки «Играть», опасных действий и переключателей. Включаются и настраиваются по громкости в Настройках → «Звуки».
- **Маленькие экраны.** Окна больше не вылезают за экран: заголовок и кнопки «Назад/Далее» всегда видны, прокручивается только содержимое. Размер окна подстраивается под рабочую область экрана.
- **Свой установщик** `ChaldLauncher-Setup.exe`: выбор папки и ярлыков, обновление поверх установленной версии, тихий режим (`--silent`), удаление через «Приложения и возможности». Права администратора не нужны.

### Файлы релиза

| Файл | Для чего |
| --- | --- |
| `ChaldLauncher-Setup.exe` | Установщик для Windows (рекомендуется) |
| `ChaldLauncher-win-x64.zip` | Windows без установки: распаковать и запустить |
| `*.AppImage` | Linux, один файл |
| `*.tar.gz` | Linux, архив |

### Известные ограничения

- Установщик не подписан, поэтому Windows SmartScreen может показать предупреждение.
- Автообновление работает только в Windows. На Linux лаунчер лишь сообщает о новой версии.
- 3D-гардероб: низ модели может быть повёрнут на 180°.
