# Chald Launcher — регистрация Chald ID (в т.ч. пираты)

## Что изменено

1. **Сервер друзей по умолчанию:** `http://213.152.43.67:25913`  
   (настройки → Friends server URL)

2. **Offline / пиратский аккаунт** может регистрировать Chald ID:
   - `friends:session` больше не требует Microsoft
   - достаточно режима Offline + ник в настройках аккаунта

3. **Экран регистрации** в разделе «Друзья»:
   - если нет токена — форма «Зарегистрировать / Войти в Chald»
   - опциональный preferred Chald ID (3–20: латиница, цифры, `_`)
   - кнопка шлёт `POST /api/v1/auth/session` с uuid + ник

4. Сообщения об ошибках обновлены (не только Microsoft).

## Как применить

Скопируй файлы из `src/` поверх своего дерева лаунчера и пересобери:

```bash
npm install
npm run build   # или твой скрипт electron-vite
```

Нужен работающий мод/API на `213.152.43.67:25913` (см. chald-friends-mod).

## Оверлей (в стиле Discord / Steam)
- Одно прозрачное окно на весь экран поверх игры (`screen-saver` уровень, периодически поднимается заново).
- Режимы: `closed` / `hud` (идёт звонок, оверлей закрыт: только HUD, клики проходят в игру, фокус не отнимается) / `open` (затемнение, панель по центру).
- Закрытие: Ctrl+Shift+O, Esc, клик по затемнению, уход из окна (Alt+Tab).
- HUD звонка в левом верхнем углу: головы участников, золотая рамка у говорящего (анализ уровня звука через AnalyserNode).
- CSP: в `img-src` добавлен `https://mc-heads.net`, иначе головы не грузились в собранной версии.

## Второй лаунчер для тестов
- `npm run dev:second` (при запущенном `npm run dev`) или `npm run start:second` (после `npm run build`) открывает второй экземпляр с отдельным профилем `test2`: свои данные, свой аккаунт, заголовок окна `ChaldLauncher [test2]`, оверлей на Ctrl+Alt+O.
- Свой профиль: `CHALD_PROFILE=имя electron .` или `electron . --profile=имя`.

## Логин = Chald ID
- При регистрации логин отправляется и как `login`, и как `chaldId`; отдельное поле Chald ID убрано (настройки и страница «Друзья»).
- Логин: 3–20 символов, латиница, цифры и `_`; ведущий `@` отбрасывается.
- Логин привязан к нику аккаунта (Microsoft или offline): при регистрации клиент шлёт только пароль, main берёт логин и Chald ID из ника. Без offline-ника введённый логин становится ником. Вход: поле логина подставляет ник, но его можно ввести вручную (другой ПК).

## Пересоздание старых аккаунтов
- При первом запуске после обновления (нет файла `friends-account.v2` в папке данных) сохранённый токен Chald сбрасывается: аккаунт нужно зарегистрировать заново по новым правилам (логин = Chald ID = ник).
- Один раз показывается уведомление «Chald-аккаунты обновлены…» (канал `friends:legacyReset`).
- Записи на сервере друзей клиент удалить не может: старые логины остаются занятыми, пока их не почистят на сервере.

## Linux: оверлей над полноэкранной игрой
- На Linux окно оверлея само становится полноэкранным и поднимается над игрой (раньше был только «always on top», его полноэкранное окно перекрывало).
- Платформа окон на Linux — как в сессии (Wayland остаётся Wayland). Принудительно: `CHALD_OZONE=x11` (X11/XWayland) или `CHALD_OZONE=wayland`.

## Чужая сборка в чате: «Добавить и установить»
- На карточке принятой сборки есть кнопка: создаёт такой же инстанс (версия Minecraft + загрузчик), выбирает его и запускает установку.
- В сообщение теперь входят `loaderType` и `loaderVersion`; у старых сообщений загрузчик берётся из текста («Fabric 0.16.5»). Если версии загрузчика нет, берётся рекомендуемая/стабильная.
- После установки моды из списка ставятся с Modrinth, только при точном совпадении названия; сколько поставилось, покажет уведомление.

## Linux: падение GPU-процесса
- Если видеопроцесс Chromium падает дважды за запуск (например, нечитаемый `/usr/lib/gbm/dri_gbm.so`), в папке данных создаётся `gpu-crashed.flag`, и следующие запуски идут на программной отрисовке без цикла падений.
- `CHALD_GPU=1` возвращает аппаратный GPU; то же делает удаление `gpu-crashed.flag`.

## Dev: второй лаунчер без запущенного Vite
- Если Vite на :5173 не отвечает (`ERR_CONNECTION_REFUSED`), окно и оверлей больше не остаются пустыми: они повторяют загрузку каждые 1,5 с, а в консоль выводится подсказка.
- `npm run dev:second` работает только вместе с `npm run dev` (Vite). Без него: `npm run second` (сборка + запуск профиля test2).
